Cómo se usa

  • Elige una herramienta a la izquierda y dibuja. Todo lo que dibujes se repite según los Sectores (mandala).
  • Sectores = 1 para dibujar sin repetición. Con Espejo cada sector también se refleja.
  • La rejilla polar imita el patrón de alfileres de un mandala. Con el imán los puntos encajan en ella.
  • Arco: arrastra la cuerda. Con apertura 180° es un medio círculo. F invierte el lado.
  • Trazo: toca puntos y termina con doble clic, Enter o el botón Terminar.
  • Seleccionar: toca un trazo para cambiarle color, grosor, tipo o simetría, o arrástralo.
  • Dos dedos o rueda del ratón para zoom. Barra espaciadora o herramienta Mano para mover la vista.
  • Guardar descarga el proyecto (.json) para seguir editándolo. PNG y SVG sirven para imprimir o compartir.
  • El diseño se guarda solo en este navegador.
